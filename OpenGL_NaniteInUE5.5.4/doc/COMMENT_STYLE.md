# 代码注释风格约定

> 管线 Shader 与 `scene.cpp` 已有较完整注释；本文约定**其余文件**的最低标准，避免重复写教程、又保证能导航到文档。

---

## 三层分工

| 层级 | 写什么 | 放哪里 |
|------|--------|--------|
| 原理 / 数学 | Nanite 概念、推导、FAQ | `README.md`、`doc/*.md` |
| 管线叙事 | Pass 顺序、数据流、易混点 | `doc/Code_Reading_Guide.md` |
| 实现锚点 | binding、字段含义、对应 doc § | 文件头 + 关键函数 |

**原则**：详细推导只保留一处（canonical doc）；代码里写 **「是什么 + 见哪一节」**，不复制长文。

---

## 文件头模板（5–10 行）

```cpp
// ==============================================================================
// 模块：<Pass 名 / 子系统名>
// 职责：<本文件在管线中的角色，一句话>
// 详述：doc/<文档名>.md §<章节>
// 注意：<易错点或 Demo 简化项，可选>
// ==============================================================================
```

Shader 文件头额外加 binding 表（见 `ClusterCull.glsl` / `NodeAndClusterCull.glsl`）。

---

## 函数注释（仅非平凡函数）

```cpp
// 输入：<参数语义>
// 输出：<返回值 / 副作用（改哪个 SSBO）>
// 见：doc/... 或 同文件 Layer N
```

行内注释只解释 **为什么**，不解释显而易见的 **是什么**。

## 结构化标记

| 标记 | 含义 |
|------|------|
| `[OPT-Pn]` | 优化待办，见 `Code_Optimization_TODO.md` |
| `[BUG-FIXED]` | 已修复，见 `Nanite_BugFixes.md` |
| `[DEMO]` | 当前 Demo 简化实现，非 UE 最终形态 |

---

## 语言

- **管线 / Nanite 相关**：中文为主，API 与 UE 标识符保留英文。
- **数学 / 相机工具**：中文函数横幅 + 英文 API 注释均可。
- **UE 参考代码**（`Res/Tools/NaniteEncode.cpp`）：保持英文，不逐行翻译。
