# SampleMask 投射与深度测试

> 返回：[README.md](./README.md) · 相关：[五行GL状态与管线阶段.md](./五行GL状态与管线阶段.md) · [Shader与渲染循环.md](./Shader与渲染循环.md)

本专题回答一个常见疑问：**深度测试（及深度写入）开着，为什么 Stochastic 半透明仍然有效？**

核心直觉：**半透明 = 往 MSAA 采样点「投射」**；掩码决定投哪些点，深度只在投中的点上裁决远近。

---

## 1. 半透明 = 往 MSAA 孔位投射

每个像素有 N 个 MSAA 采样点（本工程通常 16），各自独立存颜色 + 深度。片元算出的颜色不是「整像素糊一层」，而是往这些孔位上**投射**：

| 掩码 bit | 含义 |
|--|--|
| = 1 | 本片元**能投**到该采样点：随后做深度测试；通过则写色 + 写深 |
| = 0 | 本片元**不投**该点：不测深、不写色——孔位留给更远层或背景 |

α 控制「期望投中多少孔」。α≈0.5 → 约一半孔被近处占住，另一半仍可透出后面 → Resolve 等权平均后看起来半透。

```text
α=0.5，16x，近处玻璃只打开约 8 个点：

点:     0 1 2 3 4 5 6 7 ...
掩码:   1 0 1 0 1 0 1 0 ...
        ↑   ↑   ↑   ↑     → 投中：Z 测/写，近处颜色占住
          ↑   ↑   ↑   ↑   → 未投：孔位仍是远处/背景
```

片元侧对应：`quad.frag` 按 α 写 `gl_SampleMask[0]`（GLSL 初值全 1，此处改成随机子集）。详见 [Shader与渲染循环.md](./Shader与渲染循环.md)。

---

## 2. 不做掩码处理会怎样？

**若不做 Sample Mask 处理**（关 `GL_SAMPLE_MASK`，或掩码保持全 1）：

- 近处片元会对**全部**采样点投射；
- 深度照常开启时，近处在每个孔上都写色 + 写深；
- 后面全被挡死——看起来就像**不透明盖上去**，随机半透明失效。

因此本工程必须：`GL_MULTISAMPLE` + `GL_SAMPLE_MASK`，且 FS 按 α 改写掩码。状态细节见 [五行GL状态与管线阶段.md](./五行GL状态与管线阶段.md)。

---

## 3. 为什么深度开着仍能半透？

容易误会：深度一开 + `DepthMask TRUE` → 近处写满 Z → 后面全挡 → 半透明没了。

那是 **整像素** 都写深度时的情况。Stochastic **不是**整像素实心写满：

| | 作用 |
|--|--|
| `gl_SampleMask` | 决定 **占哪些点**（透明度 / 覆盖率） |
| 深度测试 | 只在 **被占到的点** 上比远近 |
| 没占到的点 | 不测、不写 → 后面仍可见 |

**深度开着仍能半透**，不是因为关掉了深度，而是因为半透明只投射到一部分采样点；未投中的点从未被近处写过。

深度仍然必要：不透明应能挡住透明；同一孔上两层都投中时，靠 Z 决定谁留下。

```cpp
glDepthMask(GL_TRUE);  // 投中且通过测试的点写入深度，挡住后续更远片元
```

## 4. 同孔多物体：Z 裁决表

每个 MSAA 子采样点在显存中都有独立的深度与颜色。近处红玻璃 A (Z=0.3) 与远处蓝玻璃 B (Z=0.7) 抢同一孔 i 时：

```
┌─────────────────────────┬─────────────────────────┬──────────────────────────────────────────┐
│  近处物体 A 的掩码选择   │  远处物体 B 的掩码选择   │         MSAA 子采样点 i 上的硬件裁决结果         │
├─────────────────────────┼─────────────────────────┼──────────────────────────────────────────┤
│ 孔 i 被选中 (bit i = 1) │ 孔 i 被选中 (bit i = 1) │ 碰撞！Z-Test：0.3 < 0.7 → A 覆盖 B 的色与深 │
├─────────────────────────┼─────────────────────────┼──────────────────────────────────────────┤
│ 孔 i 未选中 (bit i = 0) │ 孔 i 被选中 (bit i = 1) │ A 留空，B 写入 → 从孔 i 透出远处蓝色         │
├─────────────────────────┼─────────────────────────┼──────────────────────────────────────────┤
│ 孔 i 未选中 (bit i = 0) │ 孔 i 未选中 (bit i = 0) │ 两层均留空，孔 i 保留背景                   │
└─────────────────────────┴─────────────────────────┴──────────────────────────────────────────┘
```

要点：

1. 单个采样点内仍有 Z 裁决（近覆盖远）。
2. 物体之间是「随机抢孔」：同孔比深度；未抢到的孔留给更远层或背景。
3. **Mask 定覆盖，Z 定同点胜者**——不是「不管深度」。

## 5. 与 Resolve、与 Over 公式的关系（最终效果为何不同）

- **Resolve**：上屏前对 N 个采样点**等权平均**。半透明观感来自覆盖率统计，而非 `glBlend` / Over。
- **不等于** DP / LL 的透射加权：那些方案是「近处颜色 ×α，再乘 \((1-\alpha)\) 透出远处」；本方案是「每孔一个实心赢家，再平均」。

两层都 α=0.5 时（近 \(C_n\)、远 \(C_f\)）：

| | 期望最终色（示意） | 观感 |
|--|--|--|
| Over（DP/LL） | \(0.5\,C_n + 0.25\,C_f\)（+更远） | 近更压远，更「玻璃」 |
| Resolve（ST） | \(0.5\,C_n + 0.5\,C_f\) | 远更抢；孔级二值 → 噪 |

因此同一场景、同一 α，ST 往往更噪、远处相对更明显——不是实现 bug，是合成模型不同。总览表见 [README.md](./README.md)「最终效果差异」。

管线顺序（简化）：

```text
片元到达 → Sample Mask 筛 sample → 深度测试筛 sample → 通过的 sample 写颜色+深度
     →（帧末）MSAA Resolve 等权平均 → 屏幕
```

---

## 6. 一句话

半透明 = 按掩码往 MSAA 孔位投射；bit=1 才能投上并走深度；不做掩码则近处投满并写 Z，后面被直接盖死。深度开着仍半透，是因为只投了一部分孔。
