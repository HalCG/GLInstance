这几行出现在 **Peel 完成之后、全屏 Blend 之前**，专门配置「如何把 `fboPeel_.color`（当前层）叠进 `fboAccum_`（累积缓冲）」。五项设置是一套组合，缺一项都可能错。

---

## 这段代码在流程中的位置

```
每一层循环:
  ① Peel 画场景 → fboPeel_.color / 深度纹理   （深度测试 ON）
  ② 下面 286–290 行：改 GL 状态
  ③ 全屏 quad + depth_peeling_blend → fboAccum_  （混合 ON，深度 OFF）
  ④ 299–301 行：恢复状态，准备下一层 Peel
```

Peel 负责 **选层**；286–290 负责 **按正确公式叠色**。

## 逐项说明

### 1. `glEnable(GL_BLEND)`

**作用**：打开颜色混合。全屏 quad 输出的 `FragColor` 不会直接覆盖 `fboAccum_`，而是与已有像素按下面公式合成。

**着色器侧**（`depth_peeling_blend.frag`）只做采样，混合全在固定管线：

```glsl
FragColor = texture(texture_diffuse, textureCoord);  // 即 fboPeel_.color
```

**若没有**：每层会 **覆盖** 累积缓冲，只剩最后一层，OIT 失效。

---

### 2. `glDepthMask(GL_FALSE)`

**作用**：通过深度测试的片元 **也不写入** 深度缓冲。

**为何在 Blend 要关**：

- 目标 FBO 是 `fboAccum_`，颜色要保留，深度附件还要给 **下一层 Peel 乒乓** 用。
- 全屏 quad 覆盖全屏，若 `GL_TRUE` 会把 accum 深度写成 quad 的深度（通常 0），**破坏** 深度乒乓里存的「已剥深度」。
- `Draw(..., {false, true})` 里还会 `glClear(DEPTH)`，只清深度、不清颜色；`DepthMask(FALSE)` 避免 quad **再写坏** 深度。

**和 Peel 对比**：Peel 里 `glDepthMask(GL_TRUE)`，要把 **本层最前片元深度** 写入剥离用深度纹理。

---

### 3. `glDisable(GL_DEPTH_TEST)`

**作用**：不做深度比较，quad 的每个片元都会参与混合（写入颜色）。

**为何在 Blend 要关**：

- 全屏 quad 在 NDC 里通常 z=0，和 accum 深度比会 unpredictable。
- Blend 语义是 **全屏覆盖 + 混合**，不是「谁近谁显示」。
- Peel 已选好每层颜色；这里只需 **按像素把 peel 颜色混进 accum**。

**若没有**：quad 可能被深度挡掉，部分像素不混合 → 花屏、缺块。

---

### 4–5. `glBlendFuncSeparate(GL_DST_ALPHA, GL_ONE, GL_ZERO, GL_ONE_MINUS_SRC_ALPHA)`

**作用**：定义 Front-to-Back 的 **Under 累积**；RGB 与 Alpha 分开算。

记：

- `src` = 当前层（`fboPeel_.color`，RGBA 含 Peel 光照 + 纹理 α）
- `dst` = 累积（`fboAccum_.color`）

| 通道      | 公式                             | 因子含义                                          |
| --------- | -------------------------------- | ------------------------------------------------- |
| **RGB**   | `C_dst' = C_src × A_dst + C_dst` | 新层颜色 × **dst 的 Alpha**（剩余透射）再加旧颜色 |
| **Alpha** | `A_dst' = A_dst × (1 - A_src)`   | 用 **1 - 当前层 α** 更新「背后还剩多少权重」      |

**`dst` 初值**（`initPeelBuffers`）：`glClearColor(0,0,0,1)` → `C=0, A=1`（还没被挡）。

**叠两层例子**：

```
第1层 (C₁, α₁):  C_acc=C₁,     A_acc=1-α₁
第2层 (C₂, α₂):  C_acc=C₂(1-α₁)+C₁,  A_acc=(1-α₁)(1-α₂)
```

对应从近到远：  
`C = C₁ + C₂(1-α₁) + C₃(1-α₁)(1-α₂) + …`

**为何用 `Separate`**：  
若用普通 `glBlendFunc`，RGB/Alpha 共用一套因子，无法同时做到「RGB 用 `A_dst`」「Alpha 用 `1-A_src`」。Alpha 通道在本工程里是 **透射权重**，不是单层透明度。

**和 Final Pass 衔接**（`depth_peeling_final.frag`）：

```glsl
FragColor = frontColor + background * frontColor.a;
```

`frontColor.a` 就是 Blend 留下的 **未覆盖权重**，用来加背景。

## 五项如何协同（一张表）

| 设置                | Peel 阶段             | Blend 阶段（286–290）             |
| ------------------- | --------------------- | --------------------------------- |
| `GL_BLEND`          | 关                    | **开** → 才能累积多层             |
| `GL_DEPTH_TEST`     | **开** + `GL_LESS`    | **关** → 全屏必写到每个像素       |
| `GL_DEPTH_MASK`     | **TRUE** → 写剥离深度 | **FALSE** → 不破坏 accum 深度附件 |
| `BlendFuncSeparate` | —                     | **Front-to-Back Under** 公式      |

逻辑链：

```
Peel：深度测试 → 本层每像素一个 (C_src, A_src)
Blend：关深度 + 开混合 + 专用公式 → 写入 fboAccum_
下一层 Peel：再用 accum/peel 深度纹理做 discard
```

## 和下一行 `modelQuad_->Draw` 的关系

```cpp
modelQuad_->Draw(*shaderBlend_, fboAccum_.fbo,
                {{"texture_diffuse", fboPeel_.color.id}}, {},
                GL_TRIANGLES, {false, true});
```

| 参数             | 含义                                                         |
| ---------------- | ------------------------------------------------------------ |
| `fboAccum_.fbo`  | 混合写入累积缓冲                                             |
| `fboPeel_.color` | 作为 `texture_diffuse` 传给 blend.frag                       |
| `{false, true}`  | **不清颜色**（保留已累积），**清深度**（为乒乓换深度附件准备） |

286–290 管 **怎么混**；`Draw` 管 **往哪混、采样谁**。

## 299–301 行：为何要恢复

```cpp
glDisable(GL_BLEND);
glDepthMask(GL_TRUE);
glEnable(GL_DEPTH_TEST);
```

下一层又要 `drawSceneLayer`（Peel），必须恢复 **深度测试 + 写深度**。  
否则 Peel 无法在同一像素选出「剩余里最前」的片元。

---

## 一句话

286–290 在 Blend 阶段的作用是：**关掉深度竞争，打开混合，用 `glBlendFuncSeparate` 把当前剥离层按从近到远的 Under 公式并入 `fboAccum_`，Alpha 通道记录剩余透射，供更多层 Peel 和最终加背景使用。**
